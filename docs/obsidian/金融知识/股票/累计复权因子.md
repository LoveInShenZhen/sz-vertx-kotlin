# 累计复权因子的概念
累计复权因子是衡量**历史分红、送股、转股、配股等事件对股价累积影响**的核心指标，本质是一个 “调整系数”。其作用是消除股本变动或现金分红导致的股价 “断层”（即除权除息引起的价格跳变），使不同时间点的股价具有可比性，为技术分析、收益计算等提供连续的价格序列。

简单来说，累计复权因子反映了从某一 “基准日” 到目标交易日，所有分红送配事件对股价的总调整幅度。==通过该因子，可将除权除息后的 “断层股价” 还原为等效的 “连续股价”。==

通常, 我们以股票的上市日期为"==基准日=="

# 累计复权因子的计算方法
下面给出一份可落地的「累计复权因子」计算蓝图：  
• 以股票上市日（或任意固定基准日）为起点；  
• 只与分红、送股、转增、配股、拆合股有关，与市场行情本身无关；  
• 一旦算完，历史段的因子值**不再变动**，后续事件只在链尾追加乘法因子。

──────────────────

1. 事件定义（除权除息表）

| 字段           | 含义                 | 示例         |
| :----------- | :----------------- | :--------- |
| ex_date      | 除权除息日              | 2023-06-08 |
| cash_dvd     | 每股现金红利（税后）         | 0.5 元      |
| bonus_ratio  | 送股比例（10 送 2 → 0.2） | 0.2        |
| tran_ratio   | 转增比例（10 转 3 → 0.3） | 0.3        |
| rights_ratio | 配股比例（10 配 1 → 0.1） | 0.1        |
| rights_price | 配股价                | 6.0 元      |

一张表按 `ex_date` 升序排列即可。

──────────────────  
2. 单事件“价格缩放系数”公式

对第 i 个除权除息事件，定义

复制

```
k_i = (1 + bonus_ratio_i + tran_ratio_i + rights_ratio_i)
      -----------------------------------------------------
      (1 + rights_ratio_i) - cash_dvd_i / pre_close_i + rights_ratio_i * rights_price_i / pre_close_i
```

解释：  
• 分子 = 除权后总股数 / 除权前总股数（扩张倍数）；  
• 分母 = 除权后理论价 / 除权前收盘价（价格压缩倍数）；  
• 因此 `k_i` 是“**把事件日之前的所有价格放大 k_i 倍**”的系数。

注：如果当天只有拆/合股，则 `k_i` 就是拆合比例；如果只有现金红利，则 `k_i = pre_close / (pre_close - cash_dvd)`。

──────────────────  
3. 累计复权因子链式计算

设上市日（基准日）因子为 1.0。  
从上市日之后第一个交易日开始，向后遍历每一天 `t`：

复制

```
cum_adj(t) = 1.0
for 每一个除权除息事件 i 且 ex_date_i ≤ t:
    cum_adj(t) *= k_i
```

• 事件顺序固定，乘法次序不影响结果；  
• 上市日到今天之间的每一天都得到一条**单调不减**的 `cum_adj` 序列；  
• 新增事件只需在链尾再乘一次 `k_new`，历史段无需重算。

──────────────────  
4. 与行情表的合并

复制

```
后复权价(t) = 未复权价(t) * cum_adj(t)
前复权价(t) = 未复权价(t) * cum_adj(t) / cum_adj(latest)
```

其中 `cum_adj(latest)` 是今天（或最近一个交易日）的累计复权因子。

```python
import pandas as pd

def build_cum_adj(ex_events: pd.DataFrame) -> pd.Series:
    """
    ex_events: 按 ex_date 升序的除权除息表
    return: 以自然交易日为 index 的累计复权因子序列
    """
    # 1. 计算每个事件的 k_i
    ex_events['k_i'] = (
        (1 + ex_events['bonus_ratio'] + ex_events['tran_ratio'] + ex_events['rights_ratio']) /
        ((1 + ex_events['rights_ratio']) -
         ex_events['cash_dvd'] / ex_events['pre_close'] +
         ex_events['rights_ratio'] * ex_events['rights_price'] / ex_events['pre_close'])
    )

    # 2. 累积乘积
    ex_events['cum_k'] = ex_events['k_i'].cumprod()

    # 3. 扩展到每日
    trading_dates = pd.date_range(ex_events['ex_date'].min(), ex_events['ex_date'].max(), freq='B')
    cum_adj = pd.Series(index=trading_dates, name='cum_adj')
    cum_adj.loc[trading_dates[0]] = 1.0

    ptr = 0
    for d in trading_dates[1:]:
        while ptr < len(ex_events) and ex_events['ex_date'].iloc[ptr] <= d:
            ptr += 1
        cum_adj.loc[d] = ex_events['cum_k'].iloc[ptr - 1] if ptr > 0 else 1.0
    return cum_adj
```

- 增量更新：每天收盘后拉一次 `adj_factor`，只需把新增日期的因子 append 到本地，历史段无需改动。
- 精度：现金红利金额保留 6 位小数，k_i 乘积保留 10 位以上，可避免长期累积误差。

### ​**如何基于除权除息表计算每日累计复权因子**​

累计复权因子（Cumulative Adjustment Factor, CAF）是一个从股票上市日开始累积的乘数，用于计算**后复权价格**。它的核心逻辑是：​**每次除权除息事件都会调整历史价格的比例关系**，而 CAF 记录了所有调整的累积影响。

---

## ​**1. 复权因子计算的核心逻辑**​

### ​**​（1）初始状态**​

- ​**上市首日**​：`CAF = 1.0`（无调整）。
    
- ​**后续每日**​：如果没有除权除息事件，`CAF`保持不变；如果有事件，则按规则调整。
    

### ​**​（2）调整规则**​

每次除权除息事件发生时，`CAF`会乘以一个**调整系数（Adjustment Ratio, AR）​**，计算公式如下：

| ​**事件类型**​ | ​**调整系数（AR）计算公式**​                                                                                    | ​**示例**​                                            |
| ---------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| ​**现金分红**​ | $AR = 1 - \frac{\text{cash\_dvd}}{P_{\text{prev}}}$                                                   | 每股分红 0.5 元，前一日收盘价 10 元 → AR=1−100.5​=0.95           |
| ​**送股**​   | $AR=1+bonus\_ratio$                                                                                   | 10 送 2 → AR=1+0.2=1.2                               |
| ​**转增股本**​ | $AR=1+tran\_ratio$                                                                                    | 10 转 3 → AR=1+0.3=1.3                               |
| ​**配股**​   | $AR = 1 + \text{rights\_ratio} \times \frac{P_{\text{prev}} - \text{rights\_price}}{P_{\text{prev}}}$ | 10 配 1（配股价 6 元），前一日收盘价 10 元 → AR=1+0.1×1010−6​=1.04 |

​**注**​：

- Pprev​= 除权除息前一日收盘价（未复权）。
    
- 如果多个事件同时发生（如分红 + 送股），则调整系数相乘：
    
    ARtotal​=ARcash​×ARbonus​×ARtran​×ARrights​
    
$$AR = 1 - \frac{\text{cash\_dvd}}{P_{\text{prev}}}$$
### ​**​（3）CAF 更新规则**​

- ​**除权除息日（ex_date）及之后**​：
    
    CAFex_date​=CAFprev​×AR
    
- ​**非除权除息日**​：
    
    CAFt​=CAFt−1​

## ​**2. 计算步骤（Python 示例）​**​

假设已有以下数据：

- ​**原始行情数据**​：`df_price`（包含 `date`和 `close`列）。
    
- ​**除权除息表**​：`df_dividend`（包含 `ex_date`, `cash_dvd`, `bonus_ratio`, `tran_ratio`, `rights_ratio`, `rights_price`）。
    

### ​**​（1）预处理数据**​

```
import pandas as pd

# 假设 df_price 是行情数据，df_dividend 是除权除息表
df_price['date'] = pd.to_datetime(df_price['date'])
df_dividend['ex_date'] = pd.to_datetime(df_dividend['ex_date'])

# 按日期排序
df_price = df_price.sort_values('date')
df_dividend = df_dividend.sort_values('ex_date')
```

### ​**​（2）计算调整系数（AR）​**​

```
def calculate_adjustment_ratio(row, prev_close):
    ar = 1.0
    # 现金分红调整
    if not pd.isna(row['cash_dvd']) and row['cash_dvd'] > 0:
        ar *= 1 - row['cash_dvd'] / prev_close
    # 送股调整
    if not pd.isna(row['bonus_ratio']) and row['bonus_ratio'] > 0:
        ar *= 1 + row['bonus_ratio']
    # 转增股本调整
    if not pd.isna(row['tran_ratio']) and row['tran_ratio'] > 0:
        ar *= 1 + row['tran_ratio']
    # 配股调整
    if not pd.isna(row['rights_ratio']) and row['rights_ratio'] > 0:
        ar *= 1 + row['rights_ratio'] * (prev_close - row['rights_price']) / prev_close
    return ar

# 计算每个除权除息事件的调整系数
df_dividend['prev_close'] = df_dividend['ex_date'].map(
    lambda x: df_price[df_price['date'] < x]['close'].iloc[-1] if not df_price[df_price['date'] < x].empty else None
)
df_dividend['adjustment_ratio'] = df_dividend.apply(
    lambda x: calculate_adjustment_ratio(x, x['prev_close']), axis=1
)
```

### ​**​（3）计算每日 CAF**​

```
# 初始化 CAF
df_price['caf'] = 1.0

# 遍历除权除息事件，更新 CAF
for _, row in df_dividend.iterrows():
    ex_date = row['ex_date']
    ar = row['adjustment_ratio']
    # 找到除权除息日及之后的日期，更新 CAF
    mask = df_price['date'] >= ex_date
    df_price.loc[mask, 'caf'] = df_price.loc[mask, 'caf'] * ar

# 检查结果
print(df_price[['date', 'close', 'caf']].tail())
```

## ​**3. 计算示例**​

### ​**​（1）示例数据**​

|日期|收盘价|事件类型|调整系数（AR）|CAF|
|---|---|---|---|---|
|2023-06-07|10.0|-|-|1.0|
|2023-06-08|9.5|现金分红 0.5 元|0.95|0.95|
|2023-06-09|10.2|10 送 2|1.2|1.14|
|2023-06-10|10.5|-|-|1.14|

### ​**​（2）计算过程**​

1. ​**2023-06-07**​（上市首日）：`CAF = 1.0`。
    
2. ​**2023-06-08**​（现金分红）：
    
    - 调整系数 AR=1−100.5​=0.95
        
    - `CAF = 1.0 * 0.95 = 0.95`
        
    
3. ​**2023-06-09**​（送股）：
    
    - 调整系数 AR=1+0.2=1.2
        
    - `CAF = 0.95 * 1.2 = 1.14`
        
    
4. ​**2023-06-10**​（无事件）：`CAF = 1.14`（保持不变）。
    

---

## ​**4. 注意事项**​

1. ​**除权除息日前一日收盘价**​：
    
    - 必须使用**未复权价格**计算调整系数，否则会导致循环依赖。
        
    
2. ​**多事件同时发生**​：
    
    - 如“分红 + 送股”，需将所有调整系数相乘。
        
    
3. ​**数据精度**​：
    
    - 长期累积可能导致 CAF 出现微小误差，建议使用高精度计算（如 `decimal`模块）。
        
    
4. ​**停牌处理**​：
    
    - 如果股票在除权除息日停牌，需调整生效日期。
        
    

---

## ​**5. 总结**​

- ​**累计复权因子（CAF）​**​ 是计算后复权价格的关键变量，每次除权除息事件都会调整其值。
    
- ​**计算步骤**​：
    
    1. 计算每个除权除息事件的调整系数（AR）。
        
    2. 从上市日开始，逐日更新 CAF（事件日及之后乘以 AR）。
        
    
- ​**应用**​：
    
    - ​**后复权价格**​ = 原始价格 × CAF
        
    - ​**前复权价格**​ = 原始价格 × (最新 CAF / 当前 CAF)
        
    

​**推荐做法**​：

- 在量化回测时，使用静态 CAF（固定截至回测日的数据），避免未来数据泄露。
    
- 使用专业数据源（如 Wind、Tushare）验证计算结果。
