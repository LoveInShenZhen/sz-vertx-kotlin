# 分钟级场景下：结论先行

**对于期货分钟级 MA，默认选 SMA；VWMA 只在特定子场景下作为补充。理由如下:**

## 一、分钟级数据的特殊性决定了答案

### 1. 分钟 bar 本身已经是“成交的聚合”

日线以上级别，一根 bar 是全天数千笔成交的浓缩，价格均值和成交均值差异巨大，VWMA 有发挥空间。但**分钟 bar 内部本来就只有几笔到几十笔成交**，每根 bar 的收盘价已经非常接近该分钟的“最后一笔成交”——VWMA 想加权的信息（微观成交分布）在分钟粒度上已经被 bar 本身压缩掉了大半。粒度越细，SMA 与 VWMA 的差异越小；粒度越粗，差异越大。分钟级处于“差异存在但不显著”的区间。

### 2. 分钟级 MA 的用途几乎都是“趋势平滑”

分钟级均线的典型用法：快慢线交叉、价格对均线的偏离过滤、多周期方向判定。这些用途的第一诉求是**稳定、可预期、平滑**——恰好是 SMA 的强项、VWMA 的弱项（权重逐 bar 波动，巨量 bar 滚入滚出时均线自身跳变）。在分钟这种高噪声粒度上，用一条自身会跳的线去滤噪声，等于用噪声滤噪声。

### 3. 分钟级成交量噪声更大

- 开盘/收盘 1 分钟、主力合约换月、大单对倒，分钟级成交量呈**重尾分布**——单根 bar 的量可能是中位量的几十倍；
- 中国期货还有**双边计量**的口径问题（部分数据源 `volume` 含开平仓重复计算）；
- 夜盘、午休前后量能结构突变。

这些都直接进入 VWMA 的权重，权重污染比价格污染更难清洗。

## 二、VWMA 在分钟级仍然胜出的子场景

不是一概而论，以下情况 VWMA 更合理：

1. **成交稀疏的合约**（你前面提到的场景）：SMA 被填充平线 bar 稀释，VWMA 的 volume=0 自动归零是结构性优势——但这本质是“用 VWMA 解决缺口问题”，而非“VWMA 本身更优”。
2. **以成本为锚的短线逻辑**：如“价格偏离近期成交成本 X 跳则反转”——分钟级 VWMA ≈ 滑动 VWAP，有真实的持仓成本含义，SMA 没有这个语义。
3. **量价确认需求**：放量突破时希望均线更快跟上，VWMA 自带该特性。

## 三、决策表

| 你的情况 | 推荐 |
|---|---|
| 活跃主力合约、趋势/交叉信号 | **SMA**，无悬念 |
| 不活跃合约、缺口多 | 填充 + **VWMA**（解决稀释），或填充 + SMA + `min_effective` 门槛 |
| 均值回复、以成交成本为锚 | **VWMA**（滑动 VWAP 语义） |
| 多合约对比/价差 | **SMA**（口径最干净；VWMA 混入流动性差异） |
| 想兼得 | SMA 定方向 + VWMA 定入场基准，并行使用 |

## 四、一句话总结

分钟级上 SMA 与 VWMA 的差距没有日线级那么大，而分钟级信号对**稳定性**的要求又比日线级高——所以默认答案反了过来：**SMA 更合理**。VWMA 在分钟级的正确定位不是“更好的均线”，而是两个专用工具：稀疏合约的缺口解药、成交成本锚。先用 SMA 跑通，确认信号被“填充稀释”或需要“成本语义”时，再局部替换为 VWMA。
